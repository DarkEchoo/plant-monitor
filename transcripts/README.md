# Raw Claude Code transcripts

At every milestone M1-M5, each partner copies their raw `.jsonl` session files
from `~/.claude/projects/` into a milestone folder under their own name. Copy
the files as-is; do not summarize, export, or retype them.

Suggested layout:

```text
transcripts/
  partner-1/M1/*.jsonl
  partner-1/M2/*.jsonl
  partner-2/M1/*.jsonl
  partner-2/M2/*.jsonl
```

Each partner will work from their own personal computers and personal Claude Code sessions.
